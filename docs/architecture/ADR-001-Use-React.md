# ADR\-001: Use React

## Status

Accepted

## Context

RetireSmart requires a modern web user interface that can evolve from a simple calculator into a richer application over time.

## Decision

Use React as the primary UI framework.

## Consequences

### Positive

- Industry standard
- Large community
- Strong TypeScript support
- Excellent Azure hosting options
- Strong AI tooling support

### Negative

- Additional concepts to learn
- Rapidly evolving ecosystem
