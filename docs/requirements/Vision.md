# RetireSmart Vision

RetireSmart helps users evaluate Social Security claiming strategies by comparing cumulative benefits across different retirement ages.

The application allows a user to enter estimated monthly Social Security benefits for claiming ages 62 through 70 and view:

- Lifetime benefits by year
- Break\-even ages
- Benefit differences between claim ages
- Optimal claiming ages based on assumed longevity

This application is also a learning platform for:

- React
- TypeScript
- Clean Code
- Unit Testing
- Mutation Testing
- C4 Architecture
- ADRs
- GitHub Actions
- Azure Services
- Containerization
